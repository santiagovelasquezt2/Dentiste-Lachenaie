# Dentiste-Lachenaie

A reusable, animation-rich dental clinic website template built with Vite + React 19 + TypeScript + Tailwind CSS v4.

Originally built for Centre Dentaire Vaillancourt St-Onge (Terrebonne, QC). See `PROJECT_INTENT.md` for the full template strategy and `CLINIC_TEMPLATE.md` for the per-clinic re-skin guide.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build

`npm run build`
